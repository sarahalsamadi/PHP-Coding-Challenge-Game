# PHP Coding Challenge Game

"An interactive web-based quiz application designed to test programming knowledge. Built with **PHP** for backend logic and **MySQL** for database management, featuring a dynamic user experience with sound effects and real-time feedback."


## 🌟 Features
* **User Authentication:** Complete Login and Sign-up system with password hashing for security.
* **Dynamic Quiz Engine:** Fetches questions from a database and handles session-based progress.
* **Timed Challenges:** Includes a countdown timer for each question to increase excitement.
* **Performance Analytics:** Calculates final scores, percentages, and provides personalized feedback.
* **Multimedia Experience:** Integrated sound effects for winning and losing scenarios.
* **Responsive Design:** Modern UI with smooth animations using CSS3 and JavaScript.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox/Animations), JavaScript.
* **Backend:** PHP (Session management, MySQLi).
* **Database:** MySQL (User data and question bank).

## 🚀 How to Run
1. Clone the repository into your local server directory (e.g., `htdocs` for XAMPP).
2. Import the `login_signup` database and create the `data` and `question` tables.
3. Configure the database credentials in `login.php` and `game.php`.
4. Open `home.php` in your browser to start the challenge.
